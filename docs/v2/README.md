# v2: Follow-up Areas

Status: forward-looking placeholder. This document records likely areas of
future work without committing designs, commands, or compatibility claims.

Possible follow-up areas include:

- persistent AVR sessions and unsolicited-event routing;
- command and control operations;
- a separate HEOS client;
- JSON and other scriptable output; and
- additional zones and broader receiver-model compatibility.

Each area requires protocol evidence, explicit capability boundaries, and live
validation where the research documentation marks behavior as unverified. v2
must preserve the transport-independent protocol layers described in
[`../../ARCHITECTURE.md`](../../ARCHITECTURE.md) and build on the evidence in
[`../research/denon-avr-ip-protocol.md`](../research/denon-avr-ip-protocol.md).
