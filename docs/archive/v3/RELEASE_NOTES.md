# Version 3.0.0 Release Notes

**Release date:** 2026-10-07

Version 3.0.0 delivers the canonical receiver session used by the CLI and
desktop app. It serializes receiver operations, preserves useful failure
evidence, and confirms state-changing requests from receiver observations.

- Added receiver-state recovery, reconnect handling, and deterministic
  verification for the X3800H session.
- Updated the desktop sound-mode experience and simplified per-receiver
  favorites.
- Consolidated current engineering guidance and archived completed phase
  records.

Receiver capabilities remain model- and evidence-bound. Unvalidated behavior
continues to report unsupported or remain read-only.
